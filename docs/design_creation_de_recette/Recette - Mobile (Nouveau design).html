# Handoff : Recettes — Nouveau design (Fresh) ## Vue d'ensemble Nouveau design de la fonctionnalité **Recette** pour l'application Fresh (suivi de stock alimentaire, anti-gaspillage), en deux modes et deux formats : - **Création / édition** — composer une recette de A à Z : photo, titre, description, métadonnées (préparation, cuisson, portions, difficulté), liste d'ingrédients structurée (quantité / unité / aliment), étapes en timeline (durée + rattachement d'ingrédients), tags. Bouton **Publier** actif seulement quand le minimum requis est saisi. - **Consultation (lecture seule)** — visualiser une recette : hero photo, méta, ingrédients cochables avec **ajusteur de portions** (les quantités se recalculent), étapes en timeline cliquables, ajout des manquants à la liste de courses. Chaque mode existe en **desktop** et en **mobile**. Les 4 écrans partagent exactement le même système visuel (tokens, typographies, composants). | Mode | Desktop | Mobile | |---|---|---| | Création | `Ajout d'une recette - Nouveau design.html` | `Recette - Mobile (Nouveau design).html` (2ᵉ téléphone) | | Consultation | `Consultation d'une recette - Nouveau design.html` | `Recette - Mobile (Nouveau design).html` (1ᵉʳ téléphone) | Desktop = single-page, largeur max 1180 px, centré sur fond crème. Mobile = frame iPhone 390 × 844, barre d'action fixe en bas. ## À propos des fichiers de design Le fichier `Ajout d'une recette - Nouveau design.html` est une **référence de design créée en HTML/CSS/JS vanilla** — un prototype interactif montrant l'apparence et le comportement attendus, **pas du code de production à copier tel quel**. La tâche est de **recréer ce design dans l'environnement existant du codebase Fresh** (React, Vue, etc.), en utilisant ses patterns, composants et librairies établis. Si aucun environnement n'existe encore, choisir le framework le plus adapté et y implémenter le design. Le prototype utilise Lucide via CDN et des variables CSS inline ; dans le codebase, s'appuyer sur le système d'icônes et les tokens de design déjà en place. ## Fidélité **Haute fidélité (hifi).** Couleurs, typographies, espacements, rayons, ombres et interactions sont définitifs. Recréer l'UI au pixel près avec les librairies et patterns existants du codebase. Toutes les valeurs exactes sont listées ci-dessous et présentes dans le HTML source. ## Règle projet — pas d'emoji Fresh n'utilise **jamais d'emoji**. Toutes les icônes sont des **icônes Lucide**. Respecter ce principe dans l'implémentation.
